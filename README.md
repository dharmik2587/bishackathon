# 🛡️ BIS Standards RAG Engine

[![Anthropic Powered](https://img.shields.io/badge/LLM-Anthropic-purple?style=for-the-badge&logo=anthropic)](https://anthropic.com)
[![Vite](https://img.shields.io/badge/Frontend-Vite%20%2B%20React-646CFF?style=for-the-badge&logo=vite)](https://vitejs.dev)
[![Tailwind CSS](https://img.shields.io/badge/Styling-Tailwind%20CSS-38B2AC?style=for-the-badge&logo=tailwind-css)](https://tailwindcss.com)

A production-grade **Retrieval-Augmented Generation (RAG)** engine designed for the **Bureau of Indian Standards (BIS)**. This system leverages a high-accuracy pipeline involving direct mapping, BM25 retrieval, and LLM query rewriting to deliver highly accurate standard recommendations with sub-second latency.

---

## 📂 Project Structure

The codebase is organized into a clean, modular structure for ease of development and deployment:

### 1. `frontend/`
Contains the Vite + React frontend dashboard.
- `src/App.tsx`: Main React component containing the search UI.
- `src/data/standards.ts`: Static fallback definitions and typing.
- `public/standards.json`: The raw BIS standards data.
- `public/standards_enriched.json`: The processed, BM25-ready dataset used by the backend.

### 2. `backend/`
Contains the core Python RAG engine and data pipelines.
- `inference.py`: The main RAG inference engine. Combines direct keyword mapping, TF-IDF/BM25 retrieval, and Anthropic LLM-based query rewriting to fetch the best standards. Run this to test against a dataset.
- `eval_script.py`: The evaluation script. Compares the retrieved outputs against the expected standards to calculate Hit Rate @3 and MRR @5.
- `enrich_standards.py`: A preprocessing script that cleans and prepares `standards.json` into `standards_enriched.json`.
- `generate_mappings.py`: A utility script that analyzes the enriched standards to auto-suggest direct keyword mappings for `inference.py`.
- `pdf_extractor.py`: A utility to parse text out of the official BIS handbook PDFs.
- `requirements.txt`: Python dependencies.

### 3. `data/`
Contains all datasets and run outputs.
- `public_test_set.json`: Publicly provided test queries.
- `private_data_set.json`: Private evaluation dataset.
- `team_results.json`: Output of the RAG engine generated by `inference.py`.
- `dataset.pdf`: Raw source documents.

---

## 🚀 Key Features

- **Multi-Stage RAG Pipeline**:
    1. **Direct Mapping**: Immediate lookup for high-confidence technical terms.
    2. **BM25 Retrieval**: Fast and robust term-frequency matching (`rank-bm25`).
    3. **LLM Query Rewrite**: Intelligently expands and rewrites queries when standard retrieval yields low confidence.
- **Domain Intelligence**: Hardcoded expansions for civil, electrical, and mechanical engineering terms to ensure accuracy.
- **Sub-second Latency**: Heavily optimized to return results in ~0.001s for direct hits.

## 🛠️ Tech Stack

- **Backend (Inference)**: Python 3.11 + rank-bm25 + Anthropic Claude (fallback)
- **Frontend**: React 19 + Vite + TypeScript + Tailwind CSS 4.0

## 📦 Getting Started

### Running the Frontend Dashboard
```bash
cd frontend
npm install
npm run dev
```

### Running the Backend Inference Engine
Ensure you have the required dependencies:
```bash
cd backend
pip install -r requirements.txt
```

Run inference on the private dataset:
```bash
python inference.py --input ../data/private_data_set.json --output ../data/team_results.json
```

Evaluate the results:
```bash
python eval_script.py --results ../data/team_results.json
```
